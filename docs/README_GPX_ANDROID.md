[Implementation Guide](#implementation-guide)\n\n## GPX Export Functionality\n\nThe system supports exporting both CVRP (Capacitated Vehicle Routing Problem) and CPP (Chinese Postman Problem) solutions to GPX format.\n\n### CVRP Solutions\n\nCVRP solutions are exported with:\n- `<wpt>` elements for depot and customer locations\n- `<trk>` elements with track segments for each vehicle route\n- Named routes for easy identification\n\nImplementation located in `backend/app/cvrp_gpx.py`\n\n### CPP Solutions\n\nCPP solutions are exported with:\n- `<wpt>` elements for all nodes in the graph\n- Detailed `<trkpt>` elements representing the Eulerian circuit\n- Extensions containing solver metadata\n\nImplementation located in `backend/app/optimize.py`\n\n## Backend API Endpoints\n\n### 1. Benchmark Script with GPX Export\n\nRun the benchmark with GPX export:\n\n```bash\ncd /path/to/project\npython benchmark.py --gpx --gpx-dir ./gpx_exports ./data\n```\n\nThis will:\n- Process all VRP instances in the data directory\n- Export both Clarke-Wright and 2-Opt solutions to GPX files\n- Save files in the specified directory (default: gpx_exports)\n\n### 2.
