## Summary

- **Keep:** Everything under “PART OF THE APP” and the app-related markdown you move into `docs/`.
- **Remove:** Build artifacts, caches, one-off benchmarks, test outputs, duplicate/large data, and the `markdown/` folder after migrating any needed content to `docs/`.
- **Markdown:** One “separated” folder = **`docs/`**. Put all app-related markdown there; keep `README.md` (and optionally `CHANGELOG.md`) at repo root.

If you want, next step can be a short **cleanup script** that: (1) creates `docs/reports/` and `docs/backend/` if needed, (2) moves the listed markdown files, and (3) deletes the listed non-app files/folders (with a dry-run option).
